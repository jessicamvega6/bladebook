# ADR-029: Every Skater Gives a Registration Number, Checked for Shape Only

## Status

**Accepted** — 2026-10-12. *Decided by the owner.*

**Extends** [ADR-025](ADR-025-many-coaches-per-skater.md) decision 1 (the `SKATER#` item is the
source of truth for who the skater is) with two required attributes, and
[ADR-002](ADR-002-client-registration.md) (client registration) with a required field at sign-up.

**Leaves unchanged** ADR-002 decision 2a and [ADR-016](ADR-016-coach-signup.md) decision 2: the
coach code is generated by BladeBook. It is **never** the coach's registration number.

Records decisions first made in `Open-Pending.md` §2b and `FeatureDecriptions/Client Sign Up`.

**Amended — 2026-10-16.** *Kim's answers (`Items to ask Kim About.md` §9, questions 1–4) and the
owner's decisions.*

- **Why the number is needed:** the rinks require each skater's number. The coach passes it on
  to the rink(s); the rinks validate it, and the coach doesn't have to. This is the stated
  purpose for §7's data minimisation.
- **Every skater must have one,** adults and learn-to-skate beginners included. Decision 1
  stands as written.
- **Nothing happens when a number lapses** in MVP: BladeBook doesn't check it. A reminder to
  renew or update the number is **Phase 3**.
- **Learn to Skate USA numbers are accepted** as a third kind of number (*owner*), so beginners
  can sign up. Decisions 2–4 gain a third value; see the notes there.
- **Coaches download the numbers for the rinks** (*owner*): a file on the coach's Students tab
  with **Student First Name, Student Last Name, Skater Number**. It holds personal data about
  skaters, many of them minors, so the download is logged as a read of personal data under
  [ADR-012](ADR-012-pii-access-logging.md). Its phase and how the name is split are Open.

**Amended — 2026-11-06.** *Decided by the owner, settling a conflict with the Harbor design
(`design/harbor/client/screens-account.js`, `acNumError`).* **US Figure Skating and Learn to
Skate USA numbers are letters and digits, 1 to 20 characters**, not digits only. Anything else
is refused with *"Use letters and numbers only."* or *"That's too long for a member number."*
The rule stays loose on purpose until the real formats are known. USA Hockey's rule is
unchanged. Decision 4 is corrected below.

## Context

On 2026-10-05 the sign-up notes added two rules: a family must enter a United States Figure
Skating Association (USFSA, now US Figure Skating) or USA Hockey registration number, and a
coach's own registration number would become their coach code.

The coach-code idea fails on validation. Neither organisation offers a lookup BladeBook can use,
so anyone could claim a real coach's number, lock that coach out and receive their families'
sign-ups. Registration numbers also aren't secret, and USA Hockey issues a new one every season.
The owner dropped it on 2026-10-12.

The skater half stands; why coaches need the number is still being asked of Kim (Open). *Settled 2026-10-16 (Kim):* the rinks require it. It puts a new piece of personal data about minors in the table, which
§7's data minimisation (`architecture.md`) has to account for.

What's known about the numbers (researched 2026-10-12, `Open-Pending.md` §2b):

- **USA Hockey:** 14 characters, 9 digits and 5 letters, new every season. One digit position is
  a check digit fixed for the season (2015–16: the 4th digit was 6). Volunteer and manager
  numbers contain "XX"; older bulletins disagree about where.
- **US Figure Skating:** no published format found. Members seem to keep their number when they
  renew. Learn to Skate USA numbers are a separate series.

## Decision

### 1. Every skater has a registration number, required at sign-up

*Decided by the owner, 2026-10-12.* Each skater gives **one** number, from **one** organisation.
It belongs to the **skater**, not the family account: a family with two skaters gives two
numbers. A family can't send a skater to a coach without one, and the same applies when a
skater is added later.

### 2. Phase 1 takes US Figure Skating or USA Hockey only

Skate Canada and Hockey Canada are **Phase 2**. A coach can still choose Canadian dollars (CAD)
at sign-up (ADR-016); only the skater's organisation list is limited.

*Amended 2026-10-16:* Phase 1 also takes **Learn to Skate USA** numbers, for beginners.

### 3. Stored on the `SKATER#` item, reaching coaches like the skater's name

| Attribute | Value |
|---|---|
| `skatingOrg` | `USFS` \| `USA_HOCKEY` \| `LEARN_TO_SKATE_USA` *(added 2026-10-16)*. Phase 2 adds `SKATE_CANADA` and `HOCKEY_CANADA`. |
| `registrationNumber` | The cleaned-up form from decision 4. |

The family edits it on its own `SKATER#` item. `consumer-family-sync` copies it onto every
coach's `STUDENT#` record for that skater, as it does the skater's name (ADR-025 decision 6).
Each coach the skater is with can see it, so a coach who wants to check it with the organisation
can.

*Added 2026-10-20 (owner):* the coach sees it on the **Students list**, in a "Skater number"
column showing the number and its organisation for each skater, and on **Waiting for
approval**, beside each skater waiting to be approved (`design/harbor/coach/static/students.html`,
`pending.html`). The number is required at sign-up (decision 1), so every skater on either list
has one; neither screen has a "no number" state. The list doesn't search by number (*owner*).
The lists are already logged reads of students under ADR-012 decision 5a, so showing the number
there adds no new logging.

### 4. Checked for shape, never for membership

The number is typed into a free-text box, so it is cleaned up and checked before it's saved, by
the client API (`api-client`) and again in the browser for a quick message:

1. trim spaces and uppercase;
2. check it against the pattern for its organisation, made only of allowed characters;
3. cap the length;
4. store the cleaned-up form.

**This checks the shape only.** It can't prove the number belongs to a real member, or that the
membership is current. A rejected number gets a message naming the expected shape (*"14
characters, 9 digits and 5 letters"*), never a hint that the number was looked up.

- **USA Hockey:** 14 characters, 9 digits and 5 letters. The season's check digit is a
  **setting**, not built into the code, because it changes every season.
- **US Figure Skating:** ~~digits only, within a loose length range~~ **letters and digits, 1 to
  20 characters** *(amended 2026-11-06, Status)*, until the real format is known from a card or
  from Kim (Open).
- **Learn to Skate USA** *(added 2026-10-16):* the same loose rule, ~~digits only within a length
  range~~ letters and digits, 1 to 20 characters *(amended 2026-11-06)*, until its format is known
  (Open).

### 5. The number is never a key

It appears in no partition key, sort key or index. Bookings, recurrences and links point at the
`studentId`, so a skater who gets a new number each season changes one attribute and nothing
else.

## Alternatives considered

- **The coach's registration number as their coach code.** Rejected 2026-10-12: it can't be
  validated, it isn't secret, and it changes. See Context.
- **Validate against the organisations.** No API, lookup service or data agreement is known
  (`Open-Pending.md` §2b, research). Revisit if one appears.
- **Optional number.** Rejected by the owner: required in Phase 1. Skaters who don't have one yet
  are an Open question, not a reason to make it optional. *Settled 2026-10-16 (Kim):* every skater must have one.
- **One number per family.** Rejected: numbers are issued to people, and a family's skaters can
  play different sports.

---

## Consequences

- **New personal data about minors.** The number joins the skater's name in what ADR-012's
  access logging and ADR-022's client isolation protect. §7's data minimisation needs the
  stated purpose (Open). *Settled 2026-10-16 (Kim):* the stated purpose is that the rinks require it.
- **The sign-up and profile screens need the organisation picker and the number box.** The
  Harbor design already has them (`design/harbor/client/screens-account.js`). The coach's
  Students list and Waiting for approval show each skater's number and organisation (*added
  2026-10-20*, `design/harbor/coach/screens-students.js`). The sign-up and profile pickers offer
  all three Phase 1 organisations (*Learn to Skate USA added to the design 2026-10-20*).
- **`consumer-family-sync` copies two more attributes.** No new function, event or permission.
- **USA Hockey families must update the number every season.** Nothing forces it in MVP; what
  happens when a number lapses is Open. *Settled 2026-10-16 (Kim):* nothing happens when a number lapses; a renewal reminder is Phase 3.
- **The season's check digit is configuration someone has to change** each USA Hockey season.
- **The seed data and the masking rules (ADR-028, ADR-011) need the number.** A masked build
  must replace it, like a name. *Settled 2026-10-20 (ADR-028): a masked build replaces it with a
  fake number in the right shape for its `skatingOrg`; the seed data uses the same kind.*

- ~~**Skaters who don't have a number yet:** adults skating for fun and learn-to-skate beginners
  (Kim §9, question 1).~~ *Settled 2026-10-16:* everyone must have one; Learn to Skate USA
  numbers are accepted.
- ~~**What happens when a number expires:** blocked from booking, a reminder, or nothing (Kim §9,
  question 3).~~ *Settled 2026-10-16:* nothing in MVP; a renewal reminder is Phase 3.
- ~~**Why the number is needed** (insurance, competition or test eligibility), so §7's data
  minimisation has a stated purpose (Kim §9, question 2).~~ *Settled 2026-10-16:* the rinks
  require it; the coach passes it on.
- **Where the USA Hockey check digit setting lives** and who changes it each season.
- **Retention:** the number lives on the `SKATER#` item, which ADR-017 keeps for the account's
  life. Confirm with the legal review.
- **The rink download's phase** (MVP or later) *(added 2026-10-16)*.
- **First and last name in the download** *(added 2026-10-16)*: the skater's name is one
  `studentName` field. Split it into first and last name at sign-up, or split it when the file
  is made.
